# Binary to Excess-3 Converter

This project converts an 8-bit binary number by adding 3 to the input.

## Input
- 8-bit binary number (`b_in`)

## Output
- 8-bit output (`b_out`)

## Working
The conversion is done using:

Binary + 3 = Output

## Example
- Input: 25
- Output: 28

## Tools
- Verilog HDL
- Cadence
