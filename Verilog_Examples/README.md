# Verilog Examples

This directory contains simple Verilog examples to help beginners understand **RTL design and industry-style problem solving**.

The goal is not just to learn Verilog syntax, but to understand:

* How to read and break down a requirement
* How an engineer approaches a design problem
* How to write clean RTL
* How to create and verify a testbench
* How to think about different test cases and corner cases

### For Industry Professionals

If you are an industry professional, you are encouraged to contribute examples and explain **how you would approach the problem in a real industry environment**, including your design decisions and verification approach.

### File Format

Please follow this naming convention:

```text
<File_name>.v       → Design file
<File_name>_tb.v    → Testbench file
```

Example:

```text
counter.v
counter_tb.v
```

Please keep the **design and testbench separate**.
